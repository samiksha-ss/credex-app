# AI Spend Audit

**Analyze and optimize your startup's AI tool spending in seconds.**

AI Spend Audit is a production-quality SaaS MVP designed to help startups identify overspending on AI tools like ChatGPT, Claude, Gemini, and Cursor. It provides deterministic, financially defensible recommendations to optimize costs through seat efficiency, tier downgrades, and market comparisons.

## 🚀 Key Features

- **Deterministic Audit Engine**: Rule-based logic (no AI hallucinations for math) to evaluate spending.
- **Seat Efficiency Analysis**: Identification of over-provisioned seats vs. actual team size.
- **Market Comparison**: Suggestions for cheaper alternative tools based on feature parity.
- **AI-Powered Insights**: Personalized qualitative summaries generated by Claude.
- **Viral Growth Loop**: Shareable, SEO-optimized public report pages with dynamic OG images.
- **Lead Capture**: Seamless integration for saving audits and booking consultations.

## 📦 Getting Started

### Prerequisites
- Node.js 20+
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/samiksha-ss/credex-app.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

### Running Tests
```bash
npm run test
```

### Linting & Formatting
```bash
npm run lint
npm run format
```
